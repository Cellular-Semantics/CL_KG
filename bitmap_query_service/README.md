# Bitmap Query Service

FastAPI service for reading roaring bitmap files generated by `anndata2rdf`.

## Endpoints
- `GET /health`
- `POST /bitmap/query`

## Environment
- `BITMAP_DIR`: directory containing `.bitmap` files
- `PORT`: HTTP port for the service process

## V1 scope
- direct `Cell_cluster` IRI lookup only
- no Neo4j resolution
- no Census queries
- no bitmap set operations yet
