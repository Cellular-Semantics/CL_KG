# Graph Query Service

FastAPI service for resolving `Cell_cluster` manifest metadata from the Neo4j graph generated by the CL_KB pipeline.

## Endpoints
- `GET /health`
- `POST /graph/query`

## Environment
- `NEO4J_URI`: Bolt URI for the Neo4j instance
- `NEO4J_USER`: Neo4j username
- `NEO4J_PASSWORD`: Neo4j password
- `NEO4J_DATABASE`: database name, defaults to `neo4j`
- `PORT`: HTTP port for the service process

## V1 scope
- accepts only `cell_labels` as input
- executes a fixed read-only parameterized Cypher query
- joins matching `Cell_cluster` nodes to `Dataset` metadata
- normalizes variable node property shapes into a cluster manifest
- does not decode bitmaps
- does not query Census
